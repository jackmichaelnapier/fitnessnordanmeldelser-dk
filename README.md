# fitnessnordanmeldelser.dk

Officiel side med kundeanmeldelser af **FitnessNord**, drevet af FitnessNord. Siden viser et udvalg af
ægte anmeldelser, der er offentliggjort på FitnessNords [Trustpilot-profil](https://www.trustpilot.com/review/www.fitnessnord.com)
og linker til den fuldstændige, aktuelle bedømmelse med samtlige anmeldelser.

Statisk webside (en enkelt selvstændig HTML-fil, ingen JavaScript) udgivet via GitHub Pages.

Anmeldelserne tilhører deres respektive forfattere. Trustpilot er et varemærke tilhørende Trustpilot A/S.
